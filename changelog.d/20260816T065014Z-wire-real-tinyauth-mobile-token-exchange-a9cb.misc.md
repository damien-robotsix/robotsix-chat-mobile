Replace manual API token entry with real tinyauth SSO token-exchange flow. New `TokenExchangeAuthProvider` opens fleet SSO login in external browser, exchanges the session for a long-lived Bearer token via `GET /auth/token`, stores it in `flutter_secure_storage`, and handles 401 re-auth. Removed the free-form API token field from Settings; added auth status display and re-login action. Added session management UI (create, switch, close, delete sessions) with history reload via `GET /events` and `GET /history`.
