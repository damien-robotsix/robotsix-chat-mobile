# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in robotsix-chat-mobile, please report it via one of these channels:

- **Email:** security@robotsix.dev (preferred)
- **GitHub Security Advisory:** [Report a vulnerability](https://github.com/damien-robotsix/robotsix-chat-mobile/security/advisories/new)

Please do **not** file a public issue. We follow a coordinated-disclosure process: report the vulnerability privately, allow us time to investigate and prepare a fix, and coordinate publication timing with us before any public disclosure.

## Response time

We aim to acknowledge vulnerability reports within **5 business days**. You can expect an initial assessment and, for confirmed vulnerabilities, a timeline to resolution within that window.

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |

Only the current `main` branch receives security patches. We recommend running the latest release.
